# Bundled data license

The files `en.words`, `ru.words`, `en.tri` and `ru.tri` in this directory are
derived data, generated by `crates/datagen` from the FrequencyWords lists:

- Source: https://github.com/hermitdave/FrequencyWords
  (`content/2018/{en,ru}/{en,ru}_50k.txt`)
- Author: Hermit Dave
- Underlying corpus: OpenSubtitles
- License: Creative Commons Attribution-ShareAlike 4.0 (CC-BY-SA-4.0),
  https://creativecommons.org/licenses/by-sa/4.0/

Changes made: words lowercased and filtered to letters of the language only,
frequencies dropped from `.words` (frequency order kept), and character
trigram log-probabilities computed from the words. These derived files are
distributed under the same CC-BY-SA-4.0 license. The rest of the repository
is MIT-licensed.
